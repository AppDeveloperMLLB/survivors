# 攻撃システム仕様書

## 1. 基本設計

### 1.1 概要
- 攻撃は一定時間ごとに自動で行われる
- プレイヤーキャラクターは共通攻撃と固有攻撃を持つ
- 攻撃にはレベルがあり、最大レベルは5
- レベルアップごとに攻撃の性能が向上
- レベルアップ時は3つの選択肢から選択可能

### 1.2 攻撃の種類
1. **共通攻撃**：すべてのキャラクターが使用可能
2. **固有攻撃**：特定のキャラクターのみが使用可能

### 1.3 攻撃の属性
各攻撃は以下の属性を持つ：
- **名前**：攻撃の識別名
- **説明**：攻撃の効果説明
- **ダメージ**：基本攻撃力
- **攻撃間隔**：攻撃が発生する秒数間隔
- **持続時間**：攻撃の効果が持続する時間
- **当たり判定**：攻撃の判定サイズ（幅、高さ）
- **特殊効果**：付加効果（スタン、スロー、範囲攻撃など）
- **レベル**：現在のレベル（1〜5）
- **所有キャラクター**：この攻撃を使用できるキャラクター（共通攻撃は"all"）

## 2. レベルアップシステム

### 2.1 レベルアップの仕組み
- キャラクターがレベルアップするごとに、攻撃の選択肢が提示される
- 提示される選択肢は3つ
- 選択肢には新しい攻撃と既存の攻撃が含まれる
- 既存の攻撃を選ぶと、その攻撃のレベルが上がる
- 新しい攻撃を選ぶと、その攻撃がキャラクターの攻撃リストに追加される

### 2.2 レベルアップによる強化
攻撃がレベルアップするごとに以下の値が強化される：
- **ダメージ**：レベルごとに30%増加
- **当たり判定**：レベルごとに20%増加
- **持続時間**：レベルごとに15%増加
- **攻撃間隔**：レベルごとに10%短縮
- **特殊効果の強化**：効果の強さや持続時間がレベルごとに向上

## 3. 攻撃の種類詳細

### 3.1 共通攻撃
すべてのキャラクターが使用できる共通の攻撃。

| 攻撃名       | ダメージ | 攻撃間隔 | 特殊効果                             | 当たり判定 |
|-------------|---------|--------|-------------------------------------|----------|
| 近接攻撃     | 中      | 短     | なし                                 | 小       |
| 投擲攻撃     | 小      | 中     | 貫通（複数の敵に当たる）               | 中       |
| 範囲攻撃     | 小      | 長     | 範囲ダメージ                         | 大       |
| 毒攻撃       | 微      | 中     | 継続ダメージ（3秒間）                 | 中       |
| 鈍化攻撃     | 小      | 中     | 敵の移動速度低下（2秒間）             | 中       |

### 3.2 キャラクター固有攻撃
各キャラクター特有の攻撃。キャラクターによって異なる。

**キャラクターA固有攻撃例：**
- **雷撃**：高ダメージ、長い攻撃間隔、スタン効果
- **炎の壁**：中ダメージ、長い攻撃間隔、持続ダメージ領域を作成

**キャラクターB固有攻撃例：**
- **氷の矢**：中ダメージ、中程度の攻撃間隔、敵を凍結
- **多重弾**：低ダメージ×複数、中程度の攻撃間隔、広範囲に複数の攻撃

## 4. 実装設計

### 4.1 攻撃クラス構造
```typescript
interface Attack {
  id: string;
  name: string;
  description: string;
  baseDamage: number;
  baseInterval: number; // 秒単位
  baseHitboxWidth: number;
  baseHitboxHeight: number;
  baseDuration: number; // 秒単位
  level: number;
  maxLevel: number;
  specialEffect?: SpecialEffect;
  availableFor: string[]; // "all" または特定のキャラクターID
}

interface SpecialEffect {
  type: 'stun' | 'slow' | 'poison' | 'burn' | 'freeze' | 'knockback' | 'pierce' | 'area';
  value: number; // 効果の強さ（%）
  duration?: number; // 効果の持続時間（秒）
}
```

### 4.2 レベル毎の強化計算
```typescript
function calculateLevelBonus(baseValue: number, level: number, increasePerLevel: number): number {
  return baseValue * Math.pow(1 + increasePerLevel, level - 1);
}

// 例：レベル3の攻撃のダメージ計算（30%ずつ増加）
const damageAtLevel3 = calculateLevelBonus(baseDamage, 3, 0.3);
```

### 4.3 攻撃選択ロジック
レベルアップ時の選択肢表示：
- 現在所持していない共通攻撃からランダムに1つ
- 現在所持していない固有攻撃からランダムに1つ
- 現在所持している攻撃からランダムに1つ（レベルが上限に達していない攻撃のみ）

### 4.4 設定ファイル
攻撃の追加やバランス調整を容易にするために、攻撃の定義は専用の設定ファイルに分離する。
```typescript
// attacks.config.ts
export const commonAttacks: AttackDefinition[] = [
  {
    id: 'melee',
    name: '近接攻撃',
    description: '前方に素早く攻撃を繰り出す',
    baseDamage: 10,
    baseInterval: 1.0,
    // その他のプロパティ...
  },
  // 他の共通攻撃...
];

export const characterSpecificAttacks: Record<string, AttackDefinition[]> = {
  'character_a': [
    {
      id: 'lightning',
      name: '雷撃',
      description: '敵を一瞬で麻痺させる電撃',
      // プロパティ...
    },
    // 他の固有攻撃...
  ],
  // 他のキャラクター...
};
```

## 5. バランス設計の指針

### 5.1 攻撃速度とダメージのバランス
- **高ダメージの攻撃**：攻撃間隔が長い
- **低ダメージの攻撃**：攻撃間隔が短い
- **特殊効果のある攻撃**：ダメージや攻撃間隔が通常より控えめ

### 5.2 DPS（秒間ダメージ）の均衡
```
DPS = baseDamage / baseInterval
```
全攻撃のDPSを近い範囲内に保つことで、どの攻撃を選んでも不利にならないよう設計する。

### 5.3 レベルによる成長曲線
レベルが上がるごとに成長率が若干低下する設計も検討可能：
```typescript
// レベル5での修正係数例
const damageModifier = 1 + (0.35 * level1) + (0.3 * level2) + (0.25 * level3) + (0.2 * level4);
```

## 6. 拡張性と保守性

### 6.1 新規攻撃の追加手順
1. 攻撃定義ファイルに新しい攻撃を追加
2. 攻撃の視覚効果とアニメーションを作成
3. 新しい特殊効果がある場合は効果処理を実装

### 6.2 バランス調整方法
- 設定ファイルの数値のみを変更することでバランス調整が可能
- パラメーター化された成長率により、レベルごとの成長曲線も容易に調整可能

### 6.3 テスト方法
- DPS計算に基づく理論値テスト
- 実プレイでの体感テスト
- 各レベルでの成長比較テスト

## 7. 今後の拡張案

### 7.1 属性システム
- 火、水、雷などの属性を攻撃に追加
- 属性相性による追加ダメージやレジスト機能

### 7.2 武器システム
- キャラクターと攻撃を分離し、装備可能な武器として実装
- 武器強化や合成システム

### 7.3 コンボシステム
- 特定の攻撃を組み合わせることで発動する特殊効果
- 時間経過で自動発動するコンボ攻撃
